# digest_v2 — the Sonnet digestion workspace

**This folder is the single working area for the v2 news digestion.**
Everything the digester reads and writes lives here or is listed here.
Governing documents: `docs/data-pipeline/SONNET_DIGEST_BRIEF.md` (the digester's system
prompt, authoritative) and `docs/data-pipeline/DIGESTION_SPEC.md` (curriculum + formula
plan).

## Layout

| Path | What | Written by |
|---|---|---|
| `../news_archive_guardian.jsonl` | INPUT. Body+timestamp article records, one line per day. Only days present here are eligible. | `guardian_fetch.py` (append-only, chronological) |
| `ready_days.txt` | Manifest of eligible days: the CONTIGUOUS body-complete prefix, regenerated by the runner before each session | runner |
| `ledger.jsonl` | The rolling event ledger — the digester's only cross-day memory (trajectory state). One line per event_key with first_seen, type, peak_mag, last summary | runner |
| `events/YYYY-MM-DD.json` | Sonnet's raw validated output for each day (audit trail; escalation results overwrite in place) | runner |
| `news_impulses_v2.jsonl` | OUTPUT. Aggregated per-day node impulses for the trainer. The qwen-era `../news_impulses.jsonl` is never touched | runner |
| `validation_report.md` | Harness results: schema, distribution priors, golden-set scores | runner |
| `golden_set.jsonl` | 50 hand-tagged headlines; regression gate for any prompt/model change | human + review |

## Eligibility & ordering rules (do not violate)

1. **Body-complete days only.** A day is eligible iff its line exists in
   `news_archive_guardian.jsonl` (this file contains only body+ts records
   by construction; the pre-body pull is parked in
   `news_archive_guardian_headlines_only.jsonl.bak` and is NOT digested).
2. **Contiguous prefix only, in strict date order.** Digestion never skips
   a gap and never jumps ahead of the fetcher: the trajectory (ledger,
   novelty, event chaining) is only valid if every prior day was digested
   first. As `guardian_fetch.py` extends the archive (it fetches
   chronologically, riding quota resets), the eligible prefix grows and
   digestion resumes from where it stopped.
3. **Resumable by construction.** The last line of `news_impulses_v2.jsonl`
   defines the resume point; `ledger.jsonl` must correspond to exactly that
   day. The runner verifies this invariant before every session and halts
   loudly on mismatch rather than digesting with a corrupted trajectory.
4. **NOTHING IS EVER DELETED.** Raw archives (`news_archive_guardian.jsonl`,
   the headlines-only `.bak`, GDELT/wiki files) and every generation of
   digested output (`events*/` folders) are permanent — re-digestion from
   scratch must always be possible. Superseded outputs are renamed
   (e.g. `events_v0_headlines/`), never removed.
